# Java 常见异常检查表

## NullPointerException

- 根据增强异常消息确认哪个变量为 `null`。
- 追溯该值来自请求参数、数据库查询、依赖注入、反序列化还是未初始化字段。
- 优先修复不应为空的数据来源；只有业务允许缺省时才使用判空或默认值。
- 检查 `Optional` 是否被无条件 `get()`，以及链式调用中间值是否可能为空。

## IndexOutOfBoundsException

- 同时记录索引值与集合长度，检查循环边界是否使用 `< size`。
- 检查过滤、删除或并发更新后，旧索引是否仍被复用。
- 字符串切片需分别验证起止位置及 `begin <= end`。

## ClassCastException

- 对比异常消息中的实际类型和目标类型。
- 检查泛型擦除、原始类型集合、反序列化目标类型和代理对象。
- 不用捕获异常或连环 `instanceof` 掩盖错误的数据模型。

## ConcurrentModificationException

- 检查增强 `for` 循环中是否直接修改当前集合。
- 单线程场景优先使用迭代器的 `remove()` 或先收集再批量修改。
- 多线程场景确认同步边界，必要时选择合适的并发集合；不要仅靠复制集合回避竞态。

## IllegalArgumentException

- 找到抛出位置声明的参数前置条件，核对边界值、枚举值、格式和单位。
- 如果来自框架，先检查调用方传入配置和版本兼容性，再考虑框架内部问题。

## 验证模板

1. 为触发条件补充最小单元测试。
2. 断言异常不再发生，并校验修复后的业务结果。
3. 对空值、边界值和错误类型各补一个反例。
4. 若问题与并发有关，使用重复执行和明确同步点验证，避免只运行一次。
