# 实验课程知识库样例

## 实验三：二分查找与复杂度分析

实验三要求学生实现有序数组上的二分查找，并在实验报告中分析时间复杂度和边界条件。

实验三提交截止时间为第 6 周周日 23:59。学生需要在实验教学平台提交源代码和实验报告两个文件。

实验报告至少包含四部分：

1. 实验目的。
2. 核心算法思路。
3. 关键代码截图。
4. 时间复杂度与测试结果分析。

如果学生只提交代码但没有提交实验报告，本次实验视为材料不完整，教师可以要求补交。

## 实验平台提交步骤

学生提交代码时，需要先登录实验教学平台，进入“我的课程”，选择当前课程后打开“实验三：二分查找与复杂度分析”。

提交步骤如下：

1. 点击“上传代码”，选择 `.java` 源文件。
2. 点击“上传报告”，选择 PDF 格式实验报告。
3. 点击“保存草稿”可以暂存，但不会正式提交。
4. 点击“提交实验”后，系统会生成提交记录。
5. 页面显示“提交成功”才代表本次提交完成。

如果上传后没有点击“提交实验”，教师端看不到正式提交记录。

## Java 空指针异常排查

Java 的 `NullPointerException` 通常表示程序访问了空对象的属性或方法。

常见原因包括：

1. 对象没有初始化就调用方法。
2. 数组或集合中的元素为 `null`。
3. 方法返回值可能为 `null`，但调用方没有判断。
4. 字符串比较时用空对象调用 `equals`。

排查时建议先查看异常堆栈的第一行代码位置，再检查该行中每个对象是否可能为 `null`。如果对象来自方法返回值，需要检查返回方法在异常输入下是否返回 `null`。

## 二分查找边界条件

二分查找要求输入数组已经按升序排列。若数组无序，二分查找结果不可靠。

推荐使用 `left <= right` 作为循环条件，并用 `mid = left + (right - left) / 2` 避免整数溢出。

当目标值小于中间值时，应将 `right` 更新为 `mid - 1`。当目标值大于中间值时，应将 `left` 更新为 `mid + 1`。如果找到目标值，直接返回下标。

二分查找在有序数组上的时间复杂度是 `O(log n)`，空间复杂度通常是 `O(1)`。
