## 第四阶段：加入Agent
使用LangGraph设计少量明确节点：
识别问题
→ 检索课程知识
→ 判断是否需要工具
→ 执行工具
→ 生成答案
→ 安全检查
→ 保存结果
不要第一版就做完全自由的Agent。教学系统更适合“有限状态图 + 受控工具”。
第一批工具建议：
search_course_knowledge
get_experiment_requirements
get_platform_guide
analyze_java_error
get_report_requirements
这些工具比通用文件读写和Shell执行更贴近产品定位，也更安全。
